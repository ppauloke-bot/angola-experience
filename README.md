# Fred AI Web System

Version: 1.0

---

# Overview

Fred AI Web System is a structured framework designed to create professional, scalable and high-quality digital experiences using AI-assisted development.

The system combines:

- design principles;
- development standards;
- UX thinking;
- performance optimization;
- SEO strategy;
- business analysis.

The objective is not simply to generate websites.

The objective is to create websites with professional-level decision making.

---

# System Philosophy

AI should not replace expertise.

AI should amplify structured thinking.

This system provides rules, frameworks and specialized knowledge so AI can operate with better context and produce higher-quality results.

---

# Folder Structure

## Core

Contains universal rules that apply to every project.

Examples:

- design principles;
- coding standards;
- performance rules;
- accessibility;
- motion guidelines.

These files should rarely change.

---

## Business-Specific

Contains rules and strategies for specific industries.

Examples:

- hospitality;
- restaurants;
- healthcare;
- fashion;
- local businesses.

These files adapt the Core system to different markets.

---

# How To Use

For a new project:

1. Create a project folder.

2. Add the required Core instructions.

3. Add the relevant Business-Specific instructions.

4. Provide the project requirements.

5. Allow the AI assistant to analyze the context before implementation.

---

Every project should follow:
