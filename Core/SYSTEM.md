# SYSTEM

Version: 1.0

---

# Purpose

This document is the master coordinator of the Fred AI Web System.

Its purpose is to define how every document within this system should be interpreted and applied.

The SYSTEM document does not replace the other documents.

It orchestrates them.

---

# Core Principle

Always think before building.

Always understand before designing.

Always review before delivering.

Never generate the first obvious solution.

---

# Reading Order

When starting a new project, follow this order:

1. CLAUDE.md
2. SYSTEM.md
3. Anti-AI-Design.md
4. Design-System.md
5. Code-Standards.md
6. Motion-Rules.md
7. Performance.md
8. Accessibility.md

10. SEO.md

Every project follows the same lifecycle:

Understand

↓

Research

↓

Plan

↓

Design

↓

Build

↓

Review

↓

↓

Never skip the review phase.

---

# Decision Hierarchy

When two documents appear to conflict, follow this priority:

1. SYSTEM.md
2. CLAUDE.md
3. Business-specific documents
4. Core documents
5. Templates

Always choose the solution that creates the best experience for the end user.

---

# Design Philosophy

Every decision should improve at least one of the following:

- clarity
- usability
- aesthetics
- performance
- accessibility
- business value

Avoid changes that improve one area while unnecessarily harming another.

---

# Continuous Self-Review

Before considering any task complete, ask:

- Is this the clearest solution?
- Is this the simplest solution?
- Does it feel human?
- Does it feel premium?
- Would an experienced designer approve it?
- Would the client be proud to publish it?

If not, continue refining.

---

# Final Principle

The goal is not to generate websites.

The goal is to build digital experiences that people remember.
