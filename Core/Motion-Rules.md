# Motion Rules

Version: 1.0

---

# Purpose

This document defines principles for creating intentional, premium and meaningful motion experiences.

Motion should improve:

- communication;
- usability;
- storytelling;
- emotional impact;
- brand perception.

Animation is not decoration.

Animation is communication.

---

# Core Principle

Every movement must have a reason.

Before adding motion, ask:

- What does this movement communicate?
- Does it improve understanding?
- Does it guide attention?
- Does it strengthen the brand?
- Would the experience be worse without it?

If the answer is no, remove it.

---

# Premium Motion Philosophy

Premium digital experiences usually have:

- fewer animations;
- better timing;
- smoother transitions;
- stronger intention.

Avoid making everything move.

Movement should feel controlled, natural and purposeful.

---

# Motion Hierarchy

Not every element deserves attention.

Prioritize motion for:

1. Brand moments
2. Important information
3. User actions
4. Supporting details

Do not animate every element equally.

---

# Timing Principles

Motion should match the purpose.

## Fast Motion

Used for:

- feedback;
- small interactions;
- interface responses.

## Medium Motion

Used for:

- section transitions;
- component reveals;
- common interactions.

## Slow Motion

Used for:

- cinematic experiences;
- storytelling;
- emotional moments.

Avoid delays that make the interface feel slow.

---

# Easing Principles

Motion should feel natural.

Avoid:

- mechanical movement;
- sudden changes;
- unnatural acceleration.

Prefer movement that feels:

- smooth;
- controlled;
- responsive.

---

# Scroll-Based Motion

Scroll interactions should create progression.

Good uses:

- storytelling;
- product explanation;
- visual transformation;
- immersive experiences.

Bad uses:

- random movement;
- effects without purpose;
- distracting interactions.

The user's scroll should feel connected to the experience.

---

# Motion Patterns

## Reveal Pattern

Purpose:

Introduce content naturally.

Used for:

- sections;
- headlines;
- images;
- important information.

Principle:

Content appears when the user reaches the correct moment.

---

## Scroll Progress Pattern

Purpose:

Create a relationship between user scrolling and visual progression.

Used for:

- cinematic sections;
- product demonstrations;
- storytelling experiences.

Examples:

- video scrubbing;
- progressive animations;
- scene transitions.

The user should feel control over the experience.

---

## Parallax Pattern

Purpose:

Create depth.

Used for:

- backgrounds;
- images;
- atmospheric elements.

Use carefully.

Too much parallax creates distraction.

---

## Sticky Storytelling Pattern

Purpose:

Keep important content visible while information changes.

Used for:

- product journeys;
- explanations;
- premium landing pages.

The interaction should feel natural.

---

## Morphing Pattern

Purpose:

Create transformation between states.

Used for:

- brand moments;
- visual transitions;
- interactive experiences.

The transformation must communicate something.

---

## Micro Interaction Pattern

Purpose:

Improve feedback and perceived quality.

Used for:

- buttons;
- navigation;
- forms;
- controls.

Small details can create premium experiences.

---

## Magnetic Interaction Pattern

Purpose:

Create responsive interaction.

Used for:

- premium buttons;
- interactive elements;
- important calls to action.

Use restraint.

---

# Hero Motion Principles

Hero sections deserve special attention.

A strong hero may use:

- cinematic video;
- controlled reveals;
- subtle movement;
- scroll interaction;
- 3D experiences.

Avoid:

- excessive text animation;
- multiple competing effects;
- distracting motion.

The hero should establish the brand immediately.

---

# Video Motion Rules

When using video:

Consider:

- loading performance;
- mobile behavior;
- accessibility;
- purpose.

Video should create:

- atmosphere;
- emotion;
- storytelling;
- understanding.

Do not use video only because it looks impressive.

---

# 3D and Immersive Experiences

3D can create memorable digital experiences when used with purpose.

Do not use 3D because it looks futuristic.

Use 3D when it improves:

- understanding;
- storytelling;
- product visualization;
- emotional impact;
- brand perception.

---

# 3D Use Cases

## Product Visualization

Use 3D when users benefit from:

- exploring different angles;
- understanding details;
- viewing configurations;
- interacting with a product.

Examples:

- products;
- vehicles;
- architecture;
- luxury objects.

---

## Environmental Storytelling

Use 3D environments to create atmosphere.

Examples:

- virtual spaces;
- architectural experiences;
- immersive brand worlds.

The environment must support the message.

---

## Interactive Objects

Allow interaction when it creates value.

Examples:

- rotation;
- exploration;
- customization;
- discovery.

Do not create interaction without purpose.

---

## Abstract Brand Experiences

3D can communicate:

- innovation;
- technology;
- creativity;
- premium positioning.

The visual language must match the brand.

---

# WebGL and Real-Time Experiences

When using technologies such as:

- WebGL;
- Three.js;
- React Three Fiber;
- shaders;
- real-time rendering;

consider:

- performance;
- loading time;
- device capability;
- accessibility.

Technology should support the experience.

---

# 3D Performance Rules

Always optimize:

- model size;
- textures;
- rendering complexity;
- loading strategy.

Prefer:

- optimized assets;
- lazy loading;
- progressive enhancement;
- mobile alternatives.

---

# 3D Anti-Patterns

Avoid:

- random floating objects;
- unnecessary 3D backgrounds;
- heavy scenes without purpose;
- experiences that distract from content.

3D should support the experience.

It should not become a distraction.

---

# Performance Rules

Motion must not damage usability.

Consider:

- device performance;
- loading impact;
- frame rate;
- reduced motion preferences.

A beautiful animation that makes the site slow is a bad animation.

---

# Accessibility

Respect users who prefer reduced motion.

Provide alternatives when necessary.

Motion should never prevent access to information.

---

# Motion Anti-Patterns

Avoid:

- bouncing elements everywhere;
- excessive scroll effects;
- random rotations;
- unnecessary loading animations;
- animations that delay access.

---

# Motion Review Checklist

Before delivery:

□ Every animation has a purpose

□ Motion supports the brand

□ Timing feels natural

□ Performance remains strong

□ Mobile experience is considered

□ Reduced motion is respected

□ 3D is justified

□ The experience feels intentional

---

# Final Principle

Great motion is invisible.

Users should feel the experience, not notice the animation.

The best motion tells a story without asking for attention.

Technology is only valuable when it creates meaning.
