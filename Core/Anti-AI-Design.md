# Anti-AI Design

Version: 1.0

---

# Purpose

This document defines principles to prevent generic AI-generated design.

The goal is to create websites that feel intentional, human, memorable and professionally crafted.

AI should accelerate creativity, not replace design thinking.

---

# Core Principle

Do not create what is expected.

Create what is appropriate.

The first idea is usually the most predictable.

Always explore whether a stronger solution exists.

---

# Avoid The AI Look

Avoid patterns commonly produced by AI:

- generic hero sections;
- excessive rounded cards;
- random gradients;
- unnecessary glassmorphism;
- identical layouts;
- meaningless animations;
- decorative elements without purpose;
- generic illustrations;
- empty marketing statements.

---

# Design Intent

Every element must answer:

Why does this exist?

If there is no clear answer, remove it.

A premium design is not created by adding more.

It is created by making better decisions.

---

# Originality Framework

Before creating a section, consider:

## Context

What makes this business different?

## Audience

What does this user actually need?

## Emotion

What should the user feel?

## Action

What should the user do next?

Design should emerge from these answers.

---

# Avoid Template Thinking

Do not automatically use:

- hero;
- three feature cards;
- testimonials;
- pricing cards;
- FAQ;
- final CTA.

These structures are useful only when they serve the user's journey.

A website should be structured around the business, not around common website formulas.

---

# Visual Differentiation

Create uniqueness through:

- typography choices;
- composition;
- photography;
- spacing;
- layout rhythm;
- interaction design;
- brand personality.

Avoid relying only on colors or effects.

---

# Premium Design Principles

Premium experiences usually have:

## Restraint

Less but better.

## Confidence

The design does not need to explain itself constantly.

## Precision

Every detail feels intentional.

## Consistency

Every element belongs to the same system.

---

# Typography Rules

Typography is one of the strongest brand signals.

Avoid:

- random font combinations;
- excessive font sizes;
- poor hierarchy.

Use typography to create:

- personality;
- hierarchy;
- emotion.

---

# Spacing Rules

Avoid crowded layouts.

Whitespace creates:

- elegance;
- focus;
- readability.

Do not fill empty space just because it exists.

---

# Image Direction

Images should communicate:

- atmosphere;
- quality;
- emotion;
- context.

Avoid:

- generic stock images;
- unrelated visuals;
- images chosen only for decoration.

---

# Interaction Design

Interactions should feel intentional.

Good examples:

- meaningful transitions;
- scroll storytelling;
- subtle hover states;
- progressive disclosure.

Avoid:

- animations everywhere;
- excessive movement;
- effects that distract.

---

# Motion Patterns

Use motion as a design language.

Preferred patterns:

## Reveal

Elements appear naturally as the user discovers content.

Use for:

- sections;
- headlines;
- important information.

---

## Parallax

Different layers move at different speeds.

Use carefully for:

- storytelling;
- atmosphere;
- depth.

---

## Scroll Progress

The user's scrolling controls progression.

Use for:

- product showcases;
- cinematic storytelling;
- complex explanations.

---

## Morphing

Elements transform between states.

Use for:

- brand experiences;
- memorable interactions.

---

## Magnetic Interaction

Small responsive movements based on user interaction.

Use for:

- premium buttons;
- interactive elements.

---

# Complexity Control

Never add complexity without value.

A simple excellent interaction is better than a complex impressive-looking effect.

---

# Human Review Questions

Before approving a design:

Ask:

- Could this belong to any company?
- Does it have personality?
- Does it communicate the brand?
- Is every section necessary?
- Does it feel intentionally designed?

If the answer is no, rethink.

---

# Final Principle

The goal is not to make websites that look different.

The goal is to make websites that feel considered.

Great design is not the absence of AI.

It is the presence of human intention.
