# Website Analysis

Version: 1.0

---

# Purpose

This document defines a professional framework for analyzing existing websites.

The goal is to evaluate websites like a senior designer, UX strategist, developer and digital consultant.

The analysis should identify:

- strengths;
- weaknesses;
- missed opportunities;
- improvement priorities;
- business value.

---

# Core Principle

Do not only analyze how a website looks.

Analyze how effectively it achieves its purpose.

A website is a business tool.

---

# Analysis Mindset

Think like:

- Senior Product Designer
- UX Researcher
- Frontend Engineer
- SEO Specialist
- Conversion Strategist
- Business Consultant

Evaluate both the experience and the business impact.

---

# Analysis Structure

Every website analysis should include:

1. Executive Summary
2. First Impression
3. Brand Analysis
4. UX Analysis
5. Visual Design Analysis
6. Content Analysis
7. Conversion Analysis
8. Technical Analysis
9. Performance Analysis
10. SEO Analysis
11. Mobile Analysis
12. Accessibility Analysis
13. Opportunities
14. Improvement Roadmap
15. Final Score

---

# 1. Executive Summary

Start with a concise overview.

Include:

- what the website does well;
- biggest problems;
- biggest opportunities.

The summary should help a business owner understand the situation quickly.

---

# 2. First Impression Analysis

Evaluate the first seconds of interaction.

Ask:

- Is the purpose immediately clear?
- Does the website create trust?
- Does it feel professional?
- Does it communicate value quickly?

Users should understand:

What is this?

Why should I care?

What should I do next?

---

# 3. Brand Analysis

Evaluate:

- brand identity;
- positioning;
- consistency;
- personality.

Check:

- Does the website feel unique?
- Does it represent the business correctly?
- Does it create recognition?

---

# 4. UX Analysis

Analyze the user journey.

Evaluate:

## Navigation

Check:

- clarity;
- organization;
- ease of finding information.

## User Flow

Check:

- booking process;
- contact process;
- purchase process;
- conversion path.

Identify friction points.

---

# 5. Visual Design Analysis

Evaluate:

## Layout

Check:

- hierarchy;
- spacing;
- balance;
- composition.

## Typography

Check:

- readability;
- personality;
- consistency.

## Colors

Check:

- brand alignment;
- contrast;
- emotional impact.

## Images

Check:

- quality;
- relevance;
- storytelling.

---

# 6. Anti-AI Design Review

Evaluate whether the website feels generic.

Look for:

- template structures;
- predictable layouts;
- excessive cards;
- unnecessary gradients;
- weak personality.

Suggest ways to create differentiation.

---

# 7. Content Analysis

Evaluate:

- clarity;
- persuasion;
- relevance.

Check:

- headlines;
- descriptions;
- calls to action.

Identify:

- vague messaging;
- missing information;
- weak communication.

---

# 8. Conversion Analysis

Analyze whether the website encourages action.

Evaluate:

- CTA placement;
- trust signals;
- booking/contact process;
- user motivation.

Identify missed opportunities.

---

# 9. Technical Analysis

Evaluate:

- framework;
- architecture;
- code quality;
- maintainability.

Look for:

- technical problems;
- outdated solutions;
- scalability issues.

---

# 10. Performance Analysis

Evaluate:

- loading speed;
- images;
- videos;
- animations;
- mobile performance.

Identify:

- heavy elements;
- optimization opportunities.

---

# 11. SEO Analysis

Evaluate:

- metadata;
- headings;
- content structure;
- keywords;
- local SEO.

Identify opportunities for visibility improvement.

---

# 12. Mobile Analysis

Mobile experience must be evaluated separately.

Check:

- layout adaptation;
- navigation;
- readability;
- touch interactions;
- loading performance.

---

# 13. Accessibility Analysis

Evaluate:

- contrast;
- semantic structure;
- keyboard usability;
- readable content;
- motion considerations.

---

# Scoring System

Give scores from 0-100.

## Design Quality

Visual quality and brand expression.

## User Experience

Navigation and usability.

## Conversion Potential

Ability to generate business results.

## Content Quality

Clarity and persuasion.

## Performance

Speed and optimization.

## SEO

Search visibility.

## Accessibility

Inclusive experience.

## Technical Quality

Code and architecture.

---

# Overall Score

Calculate the final score.

Interpretation:

90-100:

Exceptional website.

80-89:

Strong professional website.

70-79:

Good foundation with improvement opportunities.

60-69:

Average experience with important issues.

Below 60:

Requires significant redesign.

---

# Improvement Prioritization

Do not list improvements randomly.

Classify:

## Critical

Problems damaging business results.

## High Priority

Important improvements with strong impact.

## Medium Priority

Useful improvements.

## Low Priority

Nice-to-have enhancements.

---

# Business Opportunity Section

Always identify:

- what could increase conversions;
- what could improve customer trust;
- what could differentiate the brand;
- what services could be offered.

Think commercially.

---

# Final Report Style

The analysis should be:

- professional;
- constructive;
- specific;
- actionable.

Do not only criticize.

Highlight strengths first.

---

# Final Principle

A website analysis is not about finding mistakes.

It is about discovering potential.

The goal is to transform a website from a digital presence into a valuable business asset.
